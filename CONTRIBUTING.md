# Contributing

Changes to numerical formulas, position handling, precision or state layout need corresponding independent-reference and multi-step evidence.
Static CI does not validate ONNX/ATC/NPU behavior. Keep exact source commits and local checkpoint identities in new build records.
Do not add model weights, OM payloads, vendor installers, credentials, host-specific private paths or copied user photos to this repository.
Preserve upstream licenses and notices; describe source-specific limitations and board verification accurately.
